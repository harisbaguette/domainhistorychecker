# 해칸 — HAEKAN

한국에서 여러 업종으로 확장할 기업의 그룹명 후보.

## 이름

| 항목 | 표기 |
| --- | --- |
| 한글 | 해칸 |
| 영문 | HAEKAN |
| 도메인 표기 | haekan |
| 길이 | 한글 2음절 · 영문 6자 |

짧게 부르고 ‘칸’에서 단단하게 끝나는 이름이다. 특정 업종에 묶이지 않고, 해칸 자체를 기업의 고유명사로 쓴다.

**해칸그룹 · 해칸물산 · 해칸건설 · 해칸유통 · 해칸전자**

## 남은 확인 사항

- 말로 들을 때 ‘해칸’과 ‘헤칸’을 혼동할 수 있다.
- HAEKAN의 해외 인명 용례가 있어 전 세계에서 사용된 적 없는 문자열은 아니다.
- 과거 도메인 이력은 조회 오류로 미확인이다.
- 상표 검색은 국내 동일명과 일부 유사 표기에 한정된다. 모든 업종·국가의 유사 권리를 확인한 상태는 아니다.
- 도메인 등록 가능 여부가 이름의 독점이나 분쟁 면제를 보장하지 않는다.

현재 후보 단계이며, 최종 기업명은 미확정이다.

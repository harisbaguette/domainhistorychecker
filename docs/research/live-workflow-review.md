# 공개 사례 적용 결과

도메인 스킬을 공개 대상에 적용하고, 브랜딩 스킬은 현재 프로젝트 이름과 목적에 적용했다. 아래 도메인은 판정 구분을 확인하는 사례이며 구매 추천 목록이 아니다.

## 취득 상태와 이력

| 대상 | 관찰 | 판단 |
|---|---|---|
| example.com | RDAP 등록 레코드와 IANA 예약 규칙 확인 | 일반 신규 구매 후보에서 제외 |
| icann.org | RDAP 등록 레코드 확인 | 이미 등록된 이름. 매물 여부·판매가는 미확인 |
| kh-domain-skill-review-20261008-8ac941.com | 권한 있는 RDAP 서버가 404 반환 | 레코드 미발견. 판매처 후보 검색을 하지 않아 등록 가능 여부·가격은 미확인 |

example.com은 Wayback 스냅샷 한 개의 본문에서 문서용 예시 도메인 안내를 확인했다. 해당 한 페이지를 읽은 결과이며 과거 전체 이력의 안전 판정은 아니다.

icann.org는 Wayback API가 스냅샷을 반환했지만 해당 본문 열람은 403으로 실패했다. 과거 콘텐츠의 품질은 미확인으로 남긴다. API의 `available: true`만으로 열람 완료 처리하지 않았다.

Google 공개 상태 화면의 example.com 결과에는 현재 유해 콘텐츠 미발견이 표시됐다. 예약 도메인이 구매 가능해지는 것은 아니며, 과거 전체·백링크·Google 검색 제재에 대한 판정도 아니다. Spamhaus와 정밀 백링크 검사는 이 사례에서 수행하지 않았다.

## 신규 도메인 예산 비교

Porkbun의 비프리미엄 일반 요금표를 적용한 예산 예시다. 특정 이름의 취득 가능성이나 견적은 아니다.

| 확장자 | 첫해 등록 | 연간 갱신 | 현재 요금이 유지될 때 3년 합계 |
|---|---:|---:|---:|
| .com | USD 11.08 | USD 11.08 | USD 33.24 |
| .xyz | USD 2.04 | USD 14.21 | USD 30.46 |

첫해 할인만으로 장기 비용을 비교하지 않는다. 표의 .xyz 첫해 금액은 할인 조건이며 갱신료에는 적용하지 않았다. 실제 이름의 프리미엄 여부, 결제 시 세금·환전·부가서비스와 미래 요금 변경은 별도 확인이 필요하다.

Cloudflare Registrar를 비교한다면 네임서버 사용 조건과 IDN 지원 여부도 선택 기준에 포함한다. 이번 사례에서는 Cloudflare의 개별 후보 견적을 받지 않아 가격 순위를 매기지 않았다.

## 현재 프로젝트의 브랜드 적용 시안

기존 이름 **도메인 퀄리티 체커**를 유지한다. 기능을 바로 설명하는 장점이 있고, 독자적인 브랜드 식별력과 상표 사용 가능 여부는 별도 검토가 필요하다.

고객 가설은 도메인을 직접 구매하되 과거 이력·등록 조건·유지 비용을 함께 판단하고 싶은 운영자다. 고객 인터뷰로 확인한 사실은 아니다.

- **약속:** 도메인의 과거와 취득 조건을 확인하고, 모르는 항목까지 보여 준다.
- **소개:** 낙장도메인의 이력부터 새 브랜드에 맞는 주소와 유지 비용까지, 구매 전 판단을 돕습니다.
- **첫 화면 문구:** “구매 전, 도메인의 과거와 조건을 확인하세요.”
- **주 행동 문구:** “도메인 검토하기”
- **결과 표현:** “확인한 범위에서는 위험 신호를 찾지 못했습니다. 과거 일부 기간과 백링크는 미확인입니다.”
- **표현 원칙:** 짧은 존댓말을 쓰고 ‘완벽히 안전’, ‘검색 순위 보장’처럼 자료가 뒷받침하지 않는 약속은 쓰지 않는다.
- **시각 방향:** 이름·취득 상태·이력·비용의 읽기 순서를 분명히 한다. 상태는 색과 글자를 함께 쓰고, 웹 본문과 버튼의 대비를 확인한다.

새 브랜드 이름의 확정, 개별 상표 검색, 로고·글꼴 파일 제작, 고객 반응 시험은 이 적용 사례에서 수행하지 않았다. 실제 브랜딩 요청에서는 해당 단계까지 이어 간다. 등록·구매·결제는 사용자가 직접 한다.

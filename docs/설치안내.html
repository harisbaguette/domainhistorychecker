설치 안내 — 처음 실행할 때 나오는 경고 화면 대처법

이 프로그램의 시작 파일(시작.command / 시작.bat)에는 개발자 서명(애플·마이크로소프트에 돈을 내고 받는 신분 도장)이 없습니다. 그래서 처음 실행할 때 컴퓨터가 "모르는 파일인데 정말 열까요?" 하고 한 번 물어봅니다. 이것은 서명 없는 파일이면 무조건 나오는 정상 경고이며, 아래 그림대로 한 번만 허용하면 다음부터는 묻지 않습니다.

지금 보는 이 안내서는 인터넷 연결 없이도 열립니다 — 받은 폴더 안의 docs/설치안내.html을 두 번 누르면 됩니다.

맥(Mac)에서 — "확인되지 않은 개발자" 경고

1단계. 그냥 두 번 누르면 이런 창이 뜹니다 (열기 단추가 없음)

2단계. 파일을 오른쪽 버튼(또는 컨트롤+클릭)으로 누르고 → "열기"

3단계. 이번에 나오는 창에서 "열기"를 누르면 끝

그래도 안 되면: 시스템 설정 → 개인정보 보호 및 보안 화면 아래쪽에 "확인되지 않은 개발자…" 문구 옆의 "그래도 열기" 단추를 누르세요.

윈도(Windows)에서 — 파란 SmartScreen 경고

1단계. 시작.bat을 두 번 누르면 파란 화면이 뜰 수 있습니다

2단계. "추가 정보"를 누르면 "실행" 단추가 생깁니다

그다음은 자동입니다

  1. 검은 창이 열리고, 파이썬 실행 도구(uv)와 필요한 프로그램을 알아서 설치합니다.
  2. 화면 사진을 찍을 브라우저를 처음 한 번 내려받습니다 (수백 MB, 몇 분 걸립니다).
  3. 웹 브라우저가 저절로 열리며 http://127.0.0.1:8765/ 화면이 나옵니다.

프로그램은 내 컴퓨터 안에서만 접속되게 잠겨 있어서 다른 사람은 들어올 수 없습니다. 자세한 사용법은 같이 들어 있는 README.md를 보세요.

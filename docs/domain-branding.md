# 도메인과 브랜딩 도움받기

이 프로젝트에서 아래처럼 요청하면 된다. 도메인 구매와 결제는 직접 한다.

| 할 일 | 요청 예시 |
|---|---|
| 낙장도메인 검사 | “이 목록에서 과거 스팸 이력과 우리 사업에 맞는 매입 후보를 골라 줘.” |
| 신규 도메인 선정 | “한국 고객 대상 사진 서비스야. 브랜드 이름과 신규 도메인을 같이 찾아 줘. 연간 유지 예산은 5만 원이야.” |
| 브랜드 전체 설계 | “이 사업의 포지셔닝부터 이름, 슬로건, 말투, 로고·색·글꼴 방향까지 잡아 줘.” |
| 백링크 검토 | “내보낸 백링크 CSV를 보고 링크 출처와 앵커텍스트의 위험을 검토해 줘.” |
| 보유 도메인 정리 | “이 목록의 사용처와 갱신 비용을 비교해서 유지할 것과 정리 후보를 알려 줘.” |

직접 지정하려면 `$kh-skill-domain` 또는 `$kh-skill-branding`을 쓴다.

진행 중인 기업명 선정의 취향과 확보 조건은 [기업명 선정 기준](../branding/BRIEF.md), 검토한 이름과 현재 상태는 [후보 기록](../branding/candidates.json)에서 이어 간다.
현재 대화의 스킬 목록에 새 항목이 보이지 않아도 프로젝트 안의 지침을 읽어 사용할 수 있다.

도메인 검토는 등록 가능 여부, 이력, 브랜드 적합성, 비용을 구분해서 보여 준다.
백링크 원본이나 조회 수단이 없으면 정밀 백링크 검사는 미확인으로 남는다.
브랜딩은 사업·고객·사용할 국가와 언어를 알려 주면 구체화할 수 있다. 정해진 이름이나 자료가 있으면 함께 활용한다.

파일로 받은 결과는 별도 위치를 지정하지 않으면 `data/advisory/`에 저장한다.

스킬 파일을 고친 뒤에는 프로젝트 루트에서 `make check-skills`를 실행한다.
기존 앱의 회귀 시험까지 함께 돌리려면 `make check`를 실행한다.

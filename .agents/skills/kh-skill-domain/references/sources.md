# 필요한 때 확인할 공식 자료

정책·조회 경로·가격은 실제 작업 시 원문을 다시 연다. 이 목록의 존재를 조회 완료로 취급하지 않는다.

| 확인할 내용 | 진입점 |
|---|---|
| 등록 정보 | [ICANN Lookup](https://lookup.icann.org/), [RDAP 사용자 안내](https://www.icann.org/en/contracted-parties/registry-operators/registration-data-access-protocol/information-for-rdap-users-31-08-2018-en), [IANA RDAP 서버 목록](https://data.iana.org/rdap/dns.json) |
| 만료와 복구·갱신 비용 고지 | [ICANN ERRP](https://www.icann.org/resources/pages/errp-2013-02-28-en) |
| 삭제 대기·잠금 상태와 이전 | [EPP 상태](https://www.icann.org/resources/pages/epp-status-codes-2014-06-16-en), [기관 간 이전 정책](https://www.icann.org/en/contracted-parties/accredited-registrars/resources/domain-name-transfers/policy) |
| TLD 운영기관·국가별 규칙의 출발점 | [IANA Root Zone Database](https://www.iana.org/domains/root/db) |
| .kr·.한국 등록 자격·문자 조건 | [KRNIC 도메인이름 관리준칙](https://krnic.or.kr/jsp/infoboard/law/domManRule.jsp) |
| 예약된 예시 도메인 | [IANA Reserved Domains](https://www.iana.org/domains/reserved) |
| 과거 웹 기록 | [Internet Archive Wayback](https://web.archive.org/), [Availability API와 한계](https://archive.org/help/wayback_api.php) |
| 크롤 자료 | [Common Crawl Index](https://index.commoncrawl.org/) |
| 위험 명단 | [Spamhaus 확인](https://check.spamhaus.org/), [Google Safe Browsing 상태](https://transparencyreport.google.com/safe-browsing/search) |
| Spamhaus 접근·오류·이용 조건 | [DNSBL 이용 안내](https://www.spamhaus.org/faqs/dnsbl-usage/), [DQS 오류 코드](https://docs.spamhaus.com/datasets/docs/source/10-data-type-documentation/datasets/040-zones.html), [DBL 대상과 응답](https://www.spamhaus.org/blocklists/domain-blocklist/) |
| Safe Browsing API의 용도 제한 | [Google API 안내](https://developers.google.com/safe-browsing/) |
| 만료 도메인 악용·링크 스팸 | [Google Search 스팸 정책](https://developers.google.com/search/docs/essentials/spam-policies) |
| 한국 상표 | [KIPRIS](https://www.kipris.or.kr/khome/main.do) |
| 국제 상표와 국가·지역 검색 연결 | [WIPO Global Brand Database](https://www.wipo.int/en/web/global-brand-database) |
| 가격표의 범위·운영 제약 비교 예 | [Porkbun 공식 요금표](https://porkbun.com/products/domains), [Cloudflare 신규 등록 조건](https://developers.cloudflare.com/registrar/get-started/register-domain/) |
| 도메인 변경 후 검색 이전 | [Google 사이트 이전](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes) |

등록·갱신·프리미엄 가격은 후보를 판매하는 공식 등록기관의 개별 검색과 가격표를 확인한다.
상표는 사용할 국가·지역과 상품·서비스를 기준으로 조사한다. WIPO 한 곳에서 결과가 없다는 이유로 권리 검토를 끝내지 않는다.

근거 파일은 [근거와 판정](evidence.md)에 맞춘다. 검색 도구의 홈페이지를 열었다는 사실만으로 개별 후보를 확인했다고 쓰지 않는다.
출처 본문을 대량 복제하지 않고 판단에 필요한 사실만 요약한다.

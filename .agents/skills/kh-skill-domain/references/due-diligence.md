# 이력과 매입 실사

## 확보할 자료

취득 경로를 먼저 확인한다. 미등록, 현재 등록 중, 경매, 삭제 대기, 예약·제한, 미확인을 구분한다.
만료일이 지났다는 사실을 낙장 완료로 해석하지 않는다. 경매·백오더는 취득 보장이 아니며 추가 비용도 확인한다.
등록 정보를 설명할 때는 대상 TLD의 RDAP·레지스트리 자료를 확인한다. ccTLD의 절차에 gTLD 일정을 그대로 적용하지 않는다.

gTLD 등록 정보는 RDAP을 우선 사용한다. 공식 조회 화면이나 IANA 부트스트랩에 있는 해당 TLD 서버로 조회한다.
등록자 연락처 비공개는 개인정보 보호일 수 있으므로 악성 운영의 근거로 쓰지 않는다.
`redemptionPeriod`는 복구 기간이며 신규 등록 가능 상태가 아니다. `pendingDelete`가 다른 상태와 함께 있는지 확인하고 날짜만으로 낙장 시각을 확정하지 않는다.
일반 gTLD의 삭제 후 복구 기간과 등록기관의 만료 후 갱신·경매 기간을 구분한다. 복구 수수료와 경매 인수 조건은 해당 기관에서 확인한다.

Wayback에서 최초·최근뿐 아니라 주제·언어·디자인이 바뀐 시기와 하위 주소를 본다.
실제로 본 시기와 페이지 수, 비어 있거나 읽지 못한 구간을 근거에 기록한다.
아카이브가 없거나 접근이 제한된 것만으로 정상 또는 은폐라고 판정하지 않는다.
등록일·아카이브 최초 발견일·현재 소유 기간도 구분한다.
Wayback Availability는 가장 가까운 스냅샷 하나를 찾는 API다. 빈 `archived_snapshots`는 미보관과 현재 접근 불가를 구별하지 못한다.
`available: true`라도 반환된 보관 상태와 실제 본문을 확인한다. 스냅샷 주소만 받은 것을 페이지 검토 완료로 쓰지 않는다.
Common Crawl은 선택한 크롤 묶음과 조회 조건을 기록한다. 일부 묶음·페이지의 미발견을 전체 인터넷의 이력 없음으로 확대하지 않는다.

Spamhaus, Safe Browsing 등 위험 명단은 조회 성공 여부와 대상이 도메인인지 URL인지 함께 확인한다.
현재 미등재를 과거까지 깨끗했다는 증거로 쓰지 않는다. 목록의 업종 분류와 피싱·악성코드 등재를 구별한다.
Spamhaus는 도메인용 DBL과 IP용 목록을 구분한다. `127.255.255.*` 오류와 DBL에 IP를 질의한 `127.0.1.255`를 등재로 해석하지 않는다.
공용 리졸버 차단·쿼터·인증 오류는 미확인이다. 이용 조건에 맞는 공식 조회 또는 허용된 DQS를 사용하며 차단을 우회하지 않는다.
Google Safe Browsing 공개 상태 화면과 공식 API를 구분한다. API의 비상업용 조건을 확인하고 상업용 연동은 Web Risk의 조건을 검토한다. 화면 내부 엔드포인트를 지원되는 공개 API로 설명하지 않는다.
합법적인 업종 이름, 게시판 목차의 반복만으로 스팸을 확정하지 않는다.
숨긴 링크, 링크 판매, 해킹 삽입, 도어웨이, 대량 자동 페이지처럼 실제 운영 방식의 근거를 본다.

## 백링크 자료가 있을 때

사용자가 준 CSV나 허용된 분석 서비스에서 다음 필드를 확인한다.
출처 URL, 대상 URL, 앵커텍스트, 링크 상태, `rel`, 최초·최근 발견 시점, 참조 도메인이다.
도구마다 필드와 수집 범위가 다르므로 열을 먼저 대응시킨다. 없는 값은 `미확인`으로 둔다.

- 전체 링크 수와 독립 참조 도메인 수를 분리하고, 같은 사이트의 전체 페이지 반복 링크가 숫자를 부풀리는지 본다.
- 브랜드명·URL·일반 표현·상업 키워드 앵커의 분포와 대상 언어·업종 일치를 본다.
- 광고·디렉터리·포럼·편집 기사·동일 네트워크 링크를 맥락으로 구분한다. TLD나 언어 하나로 유해하다고 단정하지 않는다.
- 대표 링크와 위험 신호가 큰 링크의 실제 출처·도착 URL을 확인한다. 표본으로 검사했으면 전체를 검증했다고 쓰지 않는다.
- 사라진 링크, 리디렉션 연쇄, 특정 짧은 기간에 몰린 링크, 반복되는 템플릿과 소유 관계는 추가 조사 신호로 쓴다.

자료가 없으면 백링크는 미확인이다. Common Crawl에 URL이 있다는 사실로 좋은 참조 링크가 있다고 추정하지 않는다.
DR·DA·트래픽 추정치는 공급자와 측정 시점을 붙인 보조 정보이며 Google의 점수가 아니다.

## 실제 활용 가치

기존 방문자가 기대하던 내용과 새 서비스가 얼마나 이어지는지, 보존할 유용한 주소·콘텐츠가 있는지 살핀다.
아카이브의 옛 콘텐츠를 그대로 재게시할 권리가 생기는 것은 아니다.
상표·기관 사칭·과거 운영자와의 혼동을 별도로 검토한다.
검색 순위 조작을 주목적으로 하는 저가치 콘텐츠 재활용과 정상적인 브랜드·서비스 재구축을 구분한다.
검색 결과가 없다는 사실만으로 Google 제재를 확정하거나, `site:` 결과 수를 전체 색인 수로 쓰지 않는다.
소유자에게 Search Console 근거가 없으면 비공개 제재 상태는 확인되지 않은 것으로 둔다.

## 판단

확인된 악성 운영, 새 사업과 충돌하는 이름, 설명되지 않은 심각한 이력은 추천에서 제외하거나 해소 전 보류한다.
자료 공백만 있는 경우에는 위험 확정과 구분해 `조건부 검토`로 둔다.
독립적인 긍정 근거와 목적 적합성이 있을 때만 추천 후보로 올린다.
추천하더라도 백링크 공백과 취득 조건처럼 결정에 영향을 주는 미확인은 남긴다.

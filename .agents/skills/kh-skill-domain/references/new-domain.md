# 신규 도메인 선정

## 이름에서 후보로

정해진 브랜드 이름이 있으면 유지한다. 새 이름이 필요하면 [브랜딩](../../kh-skill-branding/SKILL.md)에서 고객·차별점과 네이밍 방향을 먼저 정한다.
발음 후 받아쓰기, 한국어·로마자 표기, 기억하기 쉬움, 비슷한 철자·숫자 혼동, 확장 가능성으로 후보를 줄인다.
성격이 다른 이름을 비교하고, 약한 이름을 수십 개 나열하지 않는다.

TLD는 고객이 기대하는 지역·업종, 등록 자격, 언어·이메일 호환성과 유지 예산으로 고른다.
`.com` 확보 여부만으로 브랜드를 결정하지 않는다. 길어진 접두사나 하이픈도 실제 읽힘을 보고 비교한다.
국제화 도메인은 표시 이름과 ASCII/Punycode를 같이 확인하고, 동형 문자 혼동과 쓸 서비스의 지원 여부를 확인한다.
입력 원문을 보존하고 도메인 비교에는 사용 도구의 IDNA 규칙을 적용한다. 일반 글자의 NFC 변환만으로 등록 유효성을 판정하지 않는다.
`.kr`·`.한국`은 KRNIC의 주소지·단계별 자격·문자·예약 규칙을 확인한다. 국내 주소지 조건을 한국 국적 조건으로 바꾸어 설명하지 않는다.
이미 비슷한 이름을 가진 경쟁사가 있다면 철자 한 글자만 바꾸는 방안을 우선 추천하지 않는다.

## 확인 순서

1. 실제 서비스·회사·제품 이름과 목표 국가·언어에서 겹치는지 검색한다.
2. 한국은 KIPRIS, 해외는 WIPO와 대상 국가·지역의 공식 상표 검색을 이용한다. 동일 철자뿐 아니라 발음·유사 표기·관련 상품과 서비스를 본다.
3. 상표 조사 결과는 관할, 검색어, 분류, 관찰 범위를 근거에 남긴다. 검색 결과 없음은 법적 사용 가능 보증이 아니다. 접근이 막히면 미확인으로 남긴다.
4. 판매처 공식 검색에서 후보의 정확한 이름과 취득 상태를 확인한다. 조회 날짜와 시각은 근거에 남긴다.
5. 과거 이력과 위험 흔적을 짧게 확인한다. 흔적이 있으면 [실사](due-diligence.md)로 이어 간다.
6. 소셜 계정이 필요한 경우에만 플랫폼 공식 화면에서 확인한다. 프로필 없음·404만으로 핸들 확보 가능을 확정하지 않는다.

이름 생성 단계에서는 조회 전 후보임을 알린다. 사용자가 비공개 이름을 제시하며 외부 조회를 원하지 않으면 외부 서비스에 보내지 않고 언어적 평가만 한다.
상표 분류 번호가 달라도 상품·서비스와 유통 경로가 관련될 수 있다. 출원·등록 상태와 실제 사용을 구분하고, 권리 소멸 표시만으로 이름 사용을 확정하지 않는다.
WIPO는 수록된 국가·자료만 포함하므로 목표 국가의 공식 검색을 보완한다. 미국 안내를 한국의 법적 판단으로 그대로 적용하지 않는다.

## 비용 비교

공식 판매처에서 후보 도메인에 실제 적용되는 첫해·갱신·이전·복구 비용, 통화·세금·부가서비스를 구분한다.
프리미엄 도메인은 최초 등록뿐 아니라 프리미엄 갱신 여부도 확인한다. 일반 TLD 요금표만 보고 개별 이름의 가격을 확정하지 않는다.
시장 판매가는 일반 등록비와 구분하며, 중개·에스크로·이전 비용이 별도인지 본다.

3년 예상 비용은 `최초 취득·등록 비용 + 2회 갱신 비용 + 필수 부가비용`으로 계산한다.
초기 비용에 여러 해가 포함되면 그 기간을 반영한다. 환율과 세금 조건이 다르면 기준을 맞추거나 통화별로 보여 준다.
갱신료가 없으면 3년 비용도 미확인으로 두며, 프로모션 가격이 계속된다고 가정하지 않는다.
3년 합계는 현재 요금이 유지된다는 가정의 예산이다. 미래 가격 보장으로 쓰지 않는다.
같은 조건으로 비교할 때 지원 TLD·IDN, 네임서버 변경 가능 여부, DNSSEC, 연락처 보호, 이전 제한도 확인한다.
Cloudflare Registrar처럼 특정 네임서버 사용을 요구하는 판매처는 기존 DNS 운영과의 적합성을 먼저 본다. 요금표가 싸다는 이유만으로 선택하지 않는다.
예산 초과나 프리미엄 갱신은 예쁜 이름의 장점에 묻히지 않게 표시한다.

## 구매 직전 전달

정확한 도메인, 판매처 공식 주소, 현재 취득 방식, 첫해와 갱신 비용, 선택할 등록 기간, 남은 확인사항을 준다.
사용자가 최종 금액·추가 상품·자동갱신 조건을 확인하고 직접 결제하도록 안내한다.
결제나 가입, 계정·핸들 확보를 대신하지 않는다. 검토 결과는 도메인을 예약하지 않는다.

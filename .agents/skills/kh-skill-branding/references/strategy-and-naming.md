# 전략과 이름

## 브랜드가 맡을 역할

고객의 실제 상황·선택 기준·기존 대안부터 정리한다. 인구통계만으로 고객을 정의하지 않는다.
경쟁사의 현재 이름·주장·가격을 비교할 때는 실제 공개 자료를 확인하고 관찰과 해석을 구별한다.
아직 인터뷰·매출·리뷰가 없으면 가설로 둔다. 확인하지 않은 시장 지위를 슬로건에 넣지 않는다.

브랜드 방향은 다음 문장을 구체적으로 완성할 수 있어야 한다.

> 우리는 [고객]이 [상황에서 하려는 일]을 [다른 대안과 다른 방법]으로 해결하도록 돕는다. 믿을 근거는 [실제 역량·제품 특징·증거]다.

이것은 생각을 정리하는 도구이며 최종 카피에 대괄호나 빈칸을 남기지 않는다.
추상적인 가치 세 개를 나열하는 것으로 끝내지 말고 제품·응대·메시지에서의 행동으로 연결한다.

여러 사업·제품이 있으면 한 브랜드, 하위 브랜드, 독립 브랜드 중 고객의 혼동·확장·운영 부담에 맞는 구조를 비교한다.
리브랜딩이면 바꿀 이유, 남길 이름·기억 요소, 도메인·검색·이메일·기존 고객의 전환 순서를 함께 다룬다.

## 네이밍

먼저 이름만 놓고 고객이 실제로 쓰고 싶을지 판단한 뒤 도메인과 권리를 확인한다. 등록 가능성·검색 결과 없음·짧은 철자 수는 이름의 매력을 대신하지 않는다. 가용성 때문에 매력 없는 후보만 남으면 추천을 억지로 채우지 않는다. 사용자가 거절한 이름과 같은 구조의 음절 조합을 변형해 다시 내놓지 않는다.

서로 다른 발상 방향에서 후보를 만든다. 설명형, 연상형, 조어형 중 목적에 맞는 방향을 고르고 비슷한 접두사만 바꾼 목록을 피한다.
후보 수를 맞추기 위해 약한 이름을 채우지 않는다. 비교 가능한 소수 후보와 가장 적합한 추천안을 남긴다.
기능을 바로 설명하는 이름은 이해가 쉽지만 독자적 식별과 권리 보호가 약할 수 있다. 조어·비유·연상형은 설명 비용과 발음 부담까지 비교한다.
이는 이름 선택을 위한 판단이다. 특정 유형이라는 이유로 상표 등록 가능을 확정하지 않는다. 미국 USPTO의 식별력 분류는 미국 기준임을 구분한다.

각 후보는 아래를 확인한다.

- 약속·고객·가격대와 어울리는가. 향후 제품·지역 확장을 과하게 제한하지 않는가.
- 소리 내 읽기, 한 번 듣고 적기, 한글·로마자 표기, 띄어쓰기 없는 URL에서 읽히는가.
- 목표 언어에서 뜻이 엇나가거나 불쾌한 연상이 있는가. 모르는 언어의 반응은 확인 필요로 둔다.
- 기존 서비스·상표와 이름·발음·형태가 헷갈리는가. 일반 명칭만으로 검색 식별이 어려운가.
- 도메인 비용과 취득 조건, 필요한 소셜 핸들이 현실적인가.

이름의 언어적 적합성과 도메인·상표의 확인 결과는 별개다. 조회 전에는 `후보, 외부 확인 전`이라고 쓴다.
도메인 검토에는 [신규 도메인 선정](../../kh-skill-domain/references/new-domain.md)을 적용한다.
검색 결과가 없거나 도메인을 살 수 있어도 상표 사용이 허용된다고 단정하지 않는다.

점수를 요청받으면 고객 적합성·기억·발음·구별·확장성처럼 설명 가능한 기준으로 비교한다.
자의적인 합계로 상표 충돌·예산 초과를 숨기지 않는다. 정량 점수는 판단 보조이며 시장 반응의 확률이 아니다.

실제 반응을 확인할 때는 대상 고객에게 설명 없이 이름을 읽고 무엇을 하는지 말하게 하거나 잠시 뒤 기억나는 이름을 물어본다.
직접 수행하지 않은 시험은 계획으로만 제시한다. 표본이 작으면 시장 전체 선호로 일반화하지 않는다.
비교할 때는 같은 설명·노출 시간·질문을 사용하고 후보 순서를 바꿔 순서 효과를 줄인다. 표본수와 관찰을 기록하며 임의의 점수 컷오프를 공식 브랜드 표준이라고 부르지 않는다.

# 브랜딩에서 확인할 공식 자료

브랜드 전략·네이밍의 비교 틀은 작업용 판단 기준이다. 공식 규격이나 고객 선호의 증명으로 소개하지 않는다.
법·이용 조건·검색 동작·접근성은 아래 발행자의 해당 내용을 다시 확인한다.

| 확인할 내용 | 자료와 적용 범위 |
|---|---|
| 상표 검색 범위 | [WIPO Global Brand Database](https://www.wipo.int/en/web/global-brand-database), [KIPRIS](https://www.kipris.or.kr/khome/main.do). 판매 국가와 상품·서비스별 조사 |
| 이름의 식별력 | [USPTO Strong trademarks](https://www.uspto.gov/trademarks/basics/strong-trademarks). 미국 상표 안내이며 다른 국가의 등록 심사를 대신하지 않음 |
| 유사 이름과 관련 상품·서비스 | [USPTO Likelihood of confusion](https://www.uspto.gov/trademarks/search/likelihood-confusion). 철자 일치나 같은 분류 번호만으로 판단하지 않기 |
| 웹 색·글자·상태 표현 | [WCAG 2.2](https://www.w3.org/TR/WCAG22/). 1.4.1, 1.4.3, 1.4.11과 해당 요소의 예외 확인 |
| 글꼴 이용 | [Google Fonts FAQ](https://fonts.google.com/faq), [OFL FAQ](https://openfontlicense.org/ofl-faq/). 서비스 안내와 실제 파일의 라이선스를 대조하고 로고 제작·폰트 배포·수정 조건 구분 |
| 검색에 표시되는 사이트 이름 | [Google 사이트 이름](https://developers.google.com/search/docs/appearance/site-names). 구조화 데이터와 실제 이름의 일치, 표시 보장 없음 |
| 리브랜딩으로 주소를 바꿀 때 | [Google 사이트 이전](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes). URL 대응, 리디렉션, Search Console |

등록·가격·취득 상태는 [도메인 공식 자료](../../kh-skill-domain/references/sources.md)와 연결한다.
조사 출처와 조회 시각은 브랜드북 본문에 쌓지 않고 별도 근거 파일에 둔다.

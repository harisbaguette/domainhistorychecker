API 키

Serper와 Open PageRank, OpenRouter 키가 없으면 “매입 후보”(초록) 판정이 나오지 않습니다 — 꼭 필요한 검사가 비어서 “검토 필요”(노랑)까지만 나옵니다. 키는 이 컴퓨터의 파일에만 저장되고 밖으로 나가지 않습니다. 저장된 키는 ●●●●로 가려서 보여 주며, 칸을 비워 두고 저장하면 기존 키가 그대로 유지됩니다.

발급: openrouter.ai/keys — 로그인 후 “Create key”를 누르면 됩니다.

그림으로 보는 발급 순서
  1. 위 링크를 눌러 openrouter.ai에 로그인(구글 계정으로 가능)합니다.
  2. Keys 화면에서 Create key 단추를 누르고 아무 이름이나 넣습니다.
  3. sk-or-로 시작하는 긴 글자가 한 번만 보입니다 — 바로 복사하세요.
  4. 이 화면의 칸에 붙여 넣고 “설정 저장”을 누릅니다.

발급: serper.dev/api-key — 카드 없이 무료 2,500쿼리.

그림으로 보는 발급 순서
  1. 위 링크에서 Sign up(가입)을 누릅니다 — 카드 번호는 넣지 않습니다.
  2. 가입을 마치면 바로 API Key 화면에 긴 글자가 보입니다.
  3. 복사해서 이 칸에 붙여 넣으면 끝 — 무료로 2,500번 검색할 수 있습니다.

발급: domcop.com/openpagerank — 가입하면 화면에 키가 나옵니다.

그림으로 보는 발급 순서
  1. 위 링크에서 이메일로 가입합니다(무료).
  2. 로그인하면 화면에 API Key가 바로 보입니다.
  3. 복사해서 이 칸에 붙여 넣습니다 — 한 달에 도메인 3만 개까지 무료입니다.

발급: 구글 클라우드 콘솔 — 절차가 길어 건너뛰어도 됩니다.

발급: virustotal.com — 무료는 분당 4건이라 느립니다.

# 낙장도메인 품질 체커

만료된 도메인(낙장도메인)을 대량으로 넣으면, 과거에 어떻게 쓰였는지 조사해서
**사도 되는 것 / 더 봐야 하는 것 / 걸러야 하는 것**으로 나눠 주는 컴퓨터 프로그램입니다.
인터넷 브라우저 화면에서 쓰고, 조사한 내용은 전부 내 컴퓨터 안에만 저장됩니다.

---

## 1. 처음 한 번만 하는 준비

### 맥에서

1. 받은 zip 파일을 두 번 눌러 풉니다.
2. 풀린 폴더 안의 **`시작.command`** 를 두 번 누릅니다.
3. **“확인되지 않은 개발자” 경고가 뜨면** — 서명(애플에 돈 내고 받는 도장)이 없는 파일이라 나오는 정상 경고입니다.
   - `시작.command` 파일을 **마우스 오른쪽 버튼**(또는 컨트롤+클릭)으로 누르고 → **열기** → 다시 **열기**를 누릅니다.
   - 그래도 막히면 `시스템 설정 → 개인정보 보호 및 보안`을 열고, 아래쪽 “확인되지 않은 개발자…” 옆의 **“그래도 열기”**를 누릅니다.
   - 한 번 허용하면 다음부터는 그냥 두 번 눌러 실행됩니다.

### 윈도에서

1. 받은 zip 파일을 오른쪽 버튼 → **압축 풀기**.
2. 풀린 폴더 안의 **`시작.bat`** 을 두 번 누릅니다.
3. **파란 화면(SmartScreen) 경고가 뜨면** — 역시 서명이 없어서 나오는 정상 경고입니다.
   - 가운데의 **“추가 정보”**를 누르면 아래에 **“실행”** 단추가 생깁니다. 그걸 누르면 됩니다.

### 두 화면 모두에서 일어나는 일

검은 창이 뜨고 아래 순서로 알아서 진행됩니다. 창을 닫지 말고 기다리세요.

1. `uv`(파이썬 실행 도구)가 있는지 확인 — 없으면 설치 방법 한 줄을 알려 줍니다. 그 줄을 복사해 실행한 뒤 다시 시작 파일을 누르면 됩니다.
2. 필요한 프로그램 자동 설치 (`uv sync`).
3. 화면 사진을 찍는 브라우저 자동 설치 (최초 1회, 수백 MB라 몇 분 걸립니다).
4. 프로그램이 켜지고 웹 브라우저가 저절로 열립니다 (`http://127.0.0.1:8765/`).

> 프로그램은 **내 컴퓨터에서만 접속**되게 잠겨 있습니다(127.0.0.1). 다른 사람은 접속할 수 없습니다.

## 2. 열쇠(API 키) 넣기

**키는 하나도 없어도 됩니다.** 키가 전혀 없어도 검사가 끝까지 돌고 “매입 후보”(초록)까지 나옵니다.
관리할 키는 딱 하나, AI 분석용 OpenRouter뿐입니다. “설정” 화면의 **“분석 키”**를 펼쳐서 넣고,
키는 `~/.domainchecker/config.json` 파일에만 저장되고 밖으로 나가지 않습니다.

| 키 | 꼭 필요한가 | 어디서 받나 |
|---|---|---|
| OpenRouter | 선택 (과거 본문을 AI가 읽어 줌 · 주제 역사와 추천 주제가 나옴) | https://openrouter.ai/keys |

- 검사 속도 같은 고를 것은 화면에 없습니다 — 알아서 좋은 값으로 돕니다.
- 쓰는 AI는 고르지 않습니다. 하나가 실패하면 다음 것으로 자동으로 넘어가고, 어떤 것이 답했는지는 보고서에 적힙니다.

- 판정의 뼈대가 되는 **필수 검사 다섯 개는 전부 키 없이 돕니다** — 과거 이력(웨이백), 등록 정보, 스팸 블랙리스트, 웹 색인·현재 상태, 운영방식 규칙 검사. 세이프 브라우징(구글의 위험 사이트 명단)도 구글이 공개로 열어 둔 조회 창구로 키 없이 확인합니다.
  - 색인 검사 — 세계 크롤 기록(커먼크롤)에 이 도메인 주소가 몇 개나 남아 있는지 세고, 도메인의 지금 페이지를 직접 열어 판매용 빈 페이지인지·위험 업종 문구가 남았는지 봅니다.
  - 운영방식 규칙 검사 — AI가 아니라 계산 규칙으로 봅니다. 사람 읽으라고 쓴 글이 아닌 키워드 나열, 눈에 안 보이게 숨긴 글자, 외부 링크 무더기, 해마다 똑같은 자동 생성 페이지, 도중에 바뀐 언어를 찾아냅니다.
- **OpenRouter 키를 넣으면** 과거 본문을 AI가 읽고 문맥까지 판단해 줍니다. 없으면 위 규칙 검사만으로 판정하며, 문맥을 읽어야 잡히는 것은 놓칠 수 있습니다.
- 색인 검사는 프로그램이 그 도메인의 주소로 **직접 한 번 접속**합니다. 그래서 도메인 주인 쪽 기록에 내 인터넷 주소가 남을 수 있습니다.
- 채팅·메신저에 키를 붙여 넣은 적이 있다면 **그 키는 폐기하고 새로 발급**받으세요.

## 3. 쓰는 법 — 메뉴 네 개

아래 메뉴는 **분석 의뢰 · 분석 결과 · 매입 예정 · 설정** 네 칸입니다.

1. **분석 의뢰** — 큰 칸에 도메인을 붙여 넣습니다. 줄바꿈이나 쉼표로 구분하고, 한 번에 1,000개까지 됩니다.
   `.txt` / `.csv` 파일을 골라도 됩니다. `www.`나 `https://`는 알아서 지우고 중복도 알아서 없앱니다.
   붙여 넣으면 **예상 시간과 드는 돈**이 바로 보이고, **분석 시작**을 누르면 검사가 돕니다.
   검사가 도는 중에 또 넣으면 대기줄에 서고, 지금 검사가 끝나면 자동으로 이어서 돕니다.
2. **분석 결과** — 끝난 도메인부터 한 줄씩 쌓입니다. 위 필터로 **전체 · 주인 있음 · 스팸 · 매입 후보**를 가려 봅니다.
   - 검사 순서도 이 갈래 그대로입니다: 주인이 있는 것을 먼저 거르고(분석할 것도 없이 못 사는 것),
     과거 화면(웨이백)으로 스팸 운영 이력을 거르고, 남은 것의 색인·권위 같은 값어치를 보고,
     전부 통과한 것만 **매입 후보**가 됩니다.
   - 줄을 누르면 상세가 열립니다 — 과거에 어떤 주제로 운영됐는지 시기별 역사와 그 시기의 화면 사진,
     사면 이어가기 좋은 AI 추천 주제까지 보입니다.
   - 도중에 **중단**해도 끝난 것은 저장되고, **이어서 분석**로 남은 것부터 계속합니다.
3. **매입 예정** — 매입 후보 줄 옆의 동그란 체크를 누르면 여기로 모입니다. 사기로 정한 것의 장바구니입니다.
   체크는 파일로 저장되어 앱을 껐다 켜도 남습니다.
4. **설정** — **지우기** 단추 하나와, 접어 둔 검사 키 칸이 있습니다. 지우기를 누르면 판이 올라와
   무엇을 지울지 고릅니다(주인 있음 / 스팸 / 매입 예정 표시 / 전부, 각 줄에 몇 개인지 함께 적혀 있습니다).
   고른 다음 한 번 더 물어보고 지웁니다.
5. 저장된 결과는 **7일까지만** 다시 씁니다. 그보다 오래된 것은 자동으로 다시 검사합니다 —
   "지금 등록 가능(주인 없음)" 같은 답은 하루만 지나도 뒤집히기 때문입니다.

### 판정 읽는 법

| 표시 | 뜻 |
|---|---|
| 초록 · 매입 후보 | 위험 신호가 없고 점수도 높음 |
| 노랑 · 검토 필요 | 확인 못 한 항목이 있거나, 신호가 엇갈리거나, 상표·민감 업종이 걸림 |
| 노랑 · 이력 없음(신중) | 과거 기록 자체가 없음 — 좋은 것도 나쁜 것도 아님 |
| 빨강 · 제외 | 블랙리스트 등재, 스팸 운영 확정, 색인 오염, 또는 점수 미달 |

> **점수 미달(50점 밑)인데 노랑으로 나오는 경우가 있습니다.** 필수 검사 중 하나라도 답을 못 받으면
> "제외"로 확정하지 않기 때문입니다. 이때는 상세 화면 **조심할 이유**에 "사실상 제외 대상입니다"라고 적히니,
> 노란색만 보고 사지 마시고 그 줄을 꼭 읽으세요.

> **초록도 “위험 없음 보증”이 아닙니다.** 검색엔진에만 다른 화면을 보여 주는 수법(클로킹)이나 해킹으로 심어진 스팸은
> 저장된 과거 화면만으로는 구조적으로 놓칠 수 있습니다. 돈을 걸기 전에 상세 근거를 눈으로 확인하세요.

## 4. 저장되는 곳

```
data/cache/<도메인>.json   도메인별 검사 결과 (중단·재개의 근거)
data/results.json          이번 실행 전체 결과
data/captures/*.png        화면 사진 (말기 · 위험 시기 · 주제 시기별)
data/planned.json          매입 예정으로 체크한 도메인
data/report/index.html     HTML 보고서 (검사가 끝날 때마다 자동 갱신)
~/.domainchecker/config.json   내 키와 설정
```

## 5. 개발자용

```bash
uv sync                     # 의존성 설치
uv run pytest               # 테스트
uv run domainchecker        # 서버 실행 (127.0.0.1:8765)
DOMAINCHECKER_PORT=9000 uv run domainchecker   # 포트 변경
uv run playwright install chromium             # 캡쳐용 브라우저
```

**폰 등 다른 기기에서 접속하려면** 접속 비밀번호를 반드시 정해야 합니다. 비밀번호 없이 밖으로 열면
저장해 둔 API 키가 그대로 새어 나가므로, 프로그램이 아예 켜지지 않습니다.

```bash
DOMAINCHECKER_HOST=0.0.0.0 DOMAINCHECKER_USER=원하는아이디 DOMAINCHECKER_PASSWORD=원하는비밀번호 \
DOMAINCHECKER_SECRET=$(python -c "import secrets;print(secrets.token_urlsafe(32))") uv run domainchecker
# 접속하면 우리 로그인 화면이 뜹니다. 아이디를 안 정하면 domainchecker 가 기본값입니다.
# "로그인 상태 유지"에 체크하면 30일 동안 다시 묻지 않습니다(그 기기에서만).
```

**인터넷에 올려 둔 서버(베르셀)에서 쓸 때는 API 키를 서버 설정값으로 넣습니다.** 올려 둔 서버는
설정 파일을 저장해도 잠깐 있다 지워지기 때문에, 화면에서 키를 넣어 두면 얼마 뒤 사라집니다.
올려 둔 서버는 보는 사람(열린 연결)이 없으면 잠드는 방식이라, **분석은 화면을 열어 둔 동안** 요청 한 번당 최대 5분(300초) 안에서 돕니다 — 수백 개 큰 묶음은 내 컴퓨터에서 켜서 돌리는 것이 안전합니다.
아래처럼 서버 쪽에 넣어 두면 그 서버에서는 키가 늘 붙어 있습니다(값은 베르셀이 잠가서 보관하고,
코드나 저장소에는 절대 적지 않습니다).

```bash
vercel env add OPENROUTER_API_KEY production   # 붙여 넣으라고 물어봅니다
vercel --prod                                  # 새로 올려야 반영됩니다
```

넣을 수 있는 이름: `OPENROUTER_API_KEY` 하나입니다. 화면에서 직접 넣은 키가 있으면 그쪽이 먼저입니다.
접속 비밀번호를 걸어 둔 서버에만 넣으세요 — 잠금이 없으면 아무나 들어와 내 키로 돈을 씁니다.

`DOMAINCHECKER_SECRET` 은 로그인 쪽지(쿠키)에 찍는 도장의 재료입니다. 사람이 외울 필요 없는 긴
무작위 글자를 한 번 정해 두면, 쪽지를 주운 사람이 비밀번호를 거꾸로 맞혀 보는 일을 막습니다.

**폰을 잃어버렸거나 남의 기기에 로그인한 채로 두고 왔다면 비밀번호를 바꾸세요.** 서버가 누가
로그인해 있는지 목록을 들고 있지 않아서, 이미 나간 쪽지를 하나씩 취소할 방법은 없습니다.
비밀번호를 바꾸면 도장 재료가 달라져 **모든 기기의 쪽지가 한꺼번에 무효**가 됩니다.
